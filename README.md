[![Hacktoberfest](https://img.shields.io/badge/Hacktoberfest-welcome-green.svg)](https://hacktoberfest.digitalocean.com/)  

A simple JavaScript/HTML5/CSS3 app to display your **public IP address**.

Features:
- Quickly shows your public IP address in the browser.  
- Built using vanilla JavaScript, HTML5 and CSS3 — suitable for beginners.  
- Uses a public API (via [jsontest.com](https://www.jsontest.com)) to retrieve your IP.  
- Lightweight and easy to drop into your own site or experiment with.

Live Demo:
You can see the app in action here: [http://ip.android.com.do/](http://ip.android.com.do/)  
*(Note: Availability depends on the hosting server.)*

Installation and Usage:
1. Clone the repository
   git clone https://github.com/raydelto/show_my_ip.git
   cd show_my_ip
Open index.html in your browser

You can simply double-click the file or serve it via a local HTTP server:
Copy this code
# Using Python 3.x
python3 -m http.server 8000
open http://localhost:8000/index.html

Customize as needed:
Modify the CSS in the css/ folder if you want a different look.
Adjust the JavaScript in js/ if you’d like to use a different API endpoint.
